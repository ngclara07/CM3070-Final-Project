Methodological note:
The text modality uses TF-IDF features followed by a multi-class classifier. Candidate algorithms included SVM, Random Forest, Logistic Regression, Decision Tree, Naive Bayes, and kNN. Logistic Regression is used as the correct classification alternative to ordinary Linear Regression. The final model was selected empirically using macro F1-score because this is a four-class classification problem and class-level balance is important.
