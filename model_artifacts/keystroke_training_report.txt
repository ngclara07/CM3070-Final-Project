Methodological note:
The keystroke model selection process compares several multi-class classification algorithms over typing-dynamics features. The selected model is chosen using macro F1-score as the primary criterion because all four behaviour classes are important. Accuracy is used only as a tie-breaker. The labels are heuristic pseudo-labels and should be interpreted as behavioural typing proxies rather than direct psychological ground truth.
